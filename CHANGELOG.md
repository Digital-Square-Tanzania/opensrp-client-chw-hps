## 2.0.7-SNAPSHOT — 2026-10-25

- Increment the library version code from 43 to 44.

### Fixed

- Open the existing client profile when tapping the row background or chevron.

### Release source

- Preserve the visit-edit event handling already present in the published
  2.0.6 artifact, alongside the English/Swahili-tested list UI.
